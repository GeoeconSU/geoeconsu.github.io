# Changes for the RAO Dashboard (2026-11-03)

This document records all changes made to `rao.html` during the 2026-11-03 work session: a follow-up round fixing issues found during live review of 2026-11-02's work, plus several new layout/design requests across the Overview, Analysis, Compare, and Rankings tabs. See `notes/2026-11-02.md` for the prior session.

**Note on verification this session:** the sandbox's outbound connection to Firebase had a real external TLS issue for most of this session (a cert whose validity window hadn't started yet — confirmed independently with `curl`/`openssl`, unrelated to any code here), so live sign-in wasn't available. Every fix below was instead verified by loading the real page/CSS/JS and either (a) injecting markup matching exactly what the real render functions produce, or (b) for the final pass, feeding a synthetic CSV through the real `parseMainCSV()` pipeline and driving the actual app functions (`openCountryAnalysis`, `updateComparison`, `filterRankings`, etc.) directly — exercising the real code, not a reimplementation of it.

---

## Overview tab

### Top 10 / Bottom 10 — root cause #2
2026-11-02 fixed the bar's width consistency, but the trailing group (news-delta badge + score + percentile) had no fixed anchor, so it just sat immediately after the bar with no `margin-left:auto` — meaning rows with a delta badge pushed their score/percentile ~40px further right than rows without one. Added `margin-left:auto` to that trailing group; verified every row's score/percentile now lands at the identical x-position regardless of badge presence.

## Analysis tab

### Selector box mismatch — actually fixed this time
2026-11-02's fix was silently beaten by a global `!important` rule (`.observatory select{background-color:#233049!important}`) plus a padding/min-height interaction that gave the wrapped search `<input>` and the bare `<select>` different final heights (58px vs 39px) despite identical declared sizes. Forced both to an explicit `height:42px` and overrode the select's background with a more specific selector.

### 4-Pillar Profile / Score Decomposition — equal height, TDM relocated
- `align-items:stretch` restored (the two cards are always the same height now), with Score Decomposition's waterfall chart set to `flex:1` so it fills the extra height instead of leaving blank space.
- Take-off Detection Module moved out of the split row into its own full-width card below, gauges now in one horizontal row of 4 (circles 118px → 96px), 2×2 fallback on mobile unchanged.

### Score Decomposition — horizontal scroll on narrower "laptop" widths
The pills row (`Pre-Overlay → Overlay Adj → Mkt Bonus → Final RAO`) only had a *viewport*-width breakpoint (600px) to switch to a stacked mobile layout — but this card can be narrow (e.g. ~460px) on a 1100px-wide screen just from sitting in a split column, well above that breakpoint, causing horizontal scroll. Added a **container query** (`#score-decomp { container-type: inline-size }`, `@container (max-width: 480px)`) with the same compact-layout rules, so it responds to the card's actual rendered width instead of the viewport's. Verified: at a 462px card width inside an 1100px viewport, the row now correctly switches to the stacked grid with zero scroll overflow (this would not have triggered the old viewport-only breakpoint at all).

### Archetype Peer Comparison — bar now on the same row as the country name
`.gl-peer-bar` was `display:block` with `margin-top:10px`, forcing it onto its own line below the name. Restructured the name+bar into one flex row (`.peer-row-name`), gave the bar a fixed 70px width instead of stretching. Added a container query (`#archetype-peers`) that shrinks the last two (RAO/Δ) columns and allows the bar to wrap below the name only once the card itself gets genuinely narrow (<360px), rather than fighting for space at every width.

### Strengths & Weaknesses — stat line restructured
`Avg 0.5 · Top 10% · 93th %ile` was one plain text string with `&nbsp;·&nbsp;` separators, which could wrap mid-phrase when the 2-column grid made each box narrow. Split into three `<span>`s in a `flex-wrap` row with CSS-driven `·` separators — now it wraps cleanly between whole segments (never mid-phrase), one or more per line depending on available width, and stays a single line whenever there's room (including on mobile, where the grid already gives each box more width).

### Regional Context — stat labels can now wrap without breaking alignment
"Rank in {region}" can be long (e.g. a verbose region name) and was wrapping to 2 lines while "Regional Average"/"vs Regional Avg" stayed at 1, pushing that column's value down relative to the other two. Reserved 2-line `min-height` on all 3 labels (same pattern as the 2026-11-02 pillar-strip fix) so the three big values always sit on the same row regardless of label wrap.

### Peer Comparison · All Pillars — laptop-wide single-row layout added
Per the provided mockups: added a **container query** (`#peer-comparison-content`, `@container (min-width: 560px)`) that switches from the existing 2×2 stacked-box layout (kept as the narrow/mobile fallback) to one compact row per pillar with all 4 values side by side, plus a single shared header (Country / Global Avg / Reg Avg / Top 10) instead of repeating those labels on every pillar. Verified both breakpoints render correctly, including against the real render pipeline (not just an isolated mock).

## Compare tab

### Enhanced Pillar Comparison — differential moved to the middle; redundant section removed
- Column order changed from `Pillar | C1 | C2 | Differential` to `Pillar | C1 | Differential | C2` (2-country mode only — unaffected for 3 countries, which has no differential column).
- Removed "Pillar-by-Pillar Results" from the Pillar Winners Scorecard — it duplicated this same table. Its click-to-drill-down behavior (opens the per-variable breakdown modal) moved to this table's rows instead, so that feature isn't lost.

### Expanded Differential Analysis — redesigned to match the rest of the tab
- Replaced the oversized custom title with the same `.chart-title` header style used by Enhanced Pillar Comparison, Pillar Winners Scorecard, etc.
- Removed the standalone RAO/Opportunity/Stability/Rank "bubble" cards (redundant with exactly 2 countries being compared) — RAO Score and Rank are now just two more rows in the same unified table as the 4 real pillars.
- The table now has proper `<th>` column headers with the country names (previously repeated as `"{country}: {value}"` text inside every row).
- Also fixed: this function was still reading from the legacy `OPPORTUNITY_PILLARS`/`STABILITY_PILLARS` fake-pillar approximation (same bug family fixed elsewhere on 2026-11-02) — now reads the real `pillar_*` fields directly, and the stale "All 12 Pillar Differentials" heading (there were only ever 4) is gone.

### Gap Analysis — bubbles replaced with a bordered table
Converted the `.gap-item` "bubble" cards to the same line/row style as Enhanced Pillar Comparison (bordered `<tr>`s, `.chart-title` header), and switched its data source to the real pillars for the same reason as above.

### Country score-breakdown cards (waterfall) — name alignment + 3-country row
- `.waterfall-title` now reserves 2-line height, so a wrapping name like "Czech Republic" doesn't push that card's content down relative to the others.
- Grid changed from `repeat(auto-fit, minmax(280px, 1fr))` (which wrapped a 3rd country to its own row once the row got too narrow) to `repeat(${countries.length}, 1fr)`, so exactly 3 selected countries always render in one row.

### Side quest — what's the difference between "Expanded Differential Analysis" and "Enhanced Pillar Comparison"?
They're deliberately two different lenses on the same 2-country comparison, both now sharing one visual style:
- **Enhanced Pillar Comparison** — a neutral side-by-side table of the 4 real pillars, with the higher value in each row highlighted gold. Answers "how do these two compare, pillar by pillar?"
- **Expanded Differential Analysis** — the same 4 pillars *plus* RAO Score and global Rank in one table, sorted by the size of the gap (largest differential first) with a short written "Key Insights" takeaway underneath. Answers "where is the gap biggest, and what does that mean?" — a more interpretive, magnitude-ranked view rather than a flat comparison.
- **Gap Analysis** (related, not asked about but worth noting) is a third, one-directional lens: it only lists pillars where the *second* selected country trails the first, ranked by how hard that gap would be to close — effectively "here's country 2's homework list" rather than a neutral comparison in either direction.

## Rankings tab

### Refine panel now starts level with the page title
Previously the filter panel's top aligned with the quick-stats banner, well below the actual "Find the markets that fit your thesis" heading. Measured the heading block's height (220px) and pulled the filter panel up by that amount (`margin-top:-220px`, desktop only) so its top now sits flush with the heading's top — verified both start at the identical y-position.

## Addendum — Compare tab & Rankings polish (later same day)

A further round of fixes from live review of the above, plus a few newly reported issues.

### Analysis tab

**Regional Context — "of N" added to the rank stat.** Matched the Global Benchmark card's `#12 of 162` pattern: "Rank in {region}" now shows `#3 of 12` via the existing `.regional-stat-sub` span, instead of a bare rank with no denominator.

### Compare tab

**All Variables Comparison — converted to a real `<table>`.** The 12-variable breakdown was still a custom div/grid component (`.variable-row`/`.variable-name`/`.variable-value`/`.variable-diff`, with a sticky header and a 6-column `.vars-3` variant) — its header/column alignment didn't match the rest of the tab. Rewrote it as a proper `<table>` with the exact same `<thead>`/`<tbody>` structure, gold-underlined headers, and winner/diff-pill styling as Enhanced Pillar Comparison, Expanded Differential Analysis, and Gap Analysis, for both 2- and 3-country modes. Mobile now uses the standard "stacked table" technique (row → flex, cells → wrap) instead of a bespoke flex-wrap grid. Removed the now-dead `.variable-row` CSS (including two stale legacy breakpoint rules from older rounds).

**Compare cards — Region is now a colored badge.** "Region" was the only row in each country card rendered as flat, uncolored text (`Western Europe`, `East Asia`, …) while every other row (Rank, Opportunity, Stability) has color/weight treatment. Added `regionBadge()` — reusing the same small-pill convention as `regimeBadge()`/`tosBadge()`/`archetypeBadge()` (uppercase, bordered, tinted background) — colored by continent using the palette already used in the Regional Overview chart.

**Pillar Comparison bar chart — no more blank space below it.** This card sits next to the "4-Pillar Profile Overlay" radar in a stretched grid row; the radar's 1:1 aspect ratio makes it taller than the bar chart's old fixed 220px wrapper, leaving the extra stretched height as dead space under the bars. Made `.compare-pillar-bars-wrap` `flex:1` (same dynamic-height technique as the Analysis tab's Score Decomposition fix) so the bar chart now fills whatever height the radar establishes; mobile keeps its original fixed 180–200px sizing via an explicit `flex:0 0 Npx` override (a plain `height` can't win against `flex-basis:0%` from `flex:1`, so the override has to reset `flex`, not just `height`).

**Pillar Comparison bar chart — x-axis labels angle on mobile.** The axis was deliberately kept horizontal with 2-line wrapping (see the 2026-11-02 fix) to avoid rotation, but at mobile widths the wrapped labels still collided with their neighbors. Now checks the chart wrapper's actual rendered width at render time: ≥420px stays horizontal (unchanged from before), narrower rotates the labels to 45°.

### Rankings tab

**Refine panel scrollbar now matches the site's gold thin scrollbar.** `.obs-screening-filters` had `scrollbar-width:thin` but no `scrollbar-color`, so Firefox fell back to a plain gray thin scrollbar instead of the gold-tinted one used everywhere else (chat panel, research pane, market list). Added `scrollbar-color:#c2a56d44 transparent` to match.

**Refine panel's Score Range slider no longer overflows the panel.** Found a dead CSS rule: `.obs-screening-filters .score-range-filter{width:100%}` targeted a class name (`score-range-filter`) that doesn't exist anywhere in the markup — the real element is `.score-range-slider` — so it never applied. Its two `<input type="range">`s had a fixed 120px width each, which together with their value labels added up to ~360px, well past the ~210px the 250px-wide refine sidebar actually has to offer, so the slider visibly stuck out past the panel's edge. Fixed the selector and made the inputs flex to fill the available width instead of a fixed size.

All of the above verified with the same synthetic-CSV + DOM-bypass technique as the rest of this session (bypass `#app-gate`/`canAccessTab`/`.tab-lock`, feed a hand-built CSV through the real `parseMainCSV()`, drive `switchTab`/`updateComparison` directly), checking computed styles and `getBoundingClientRect()` at both desktop and mobile viewport sizes.
